# Third-party content and sources

## Code
- **No third-party code is included.** The site's HTML, CSS, JavaScript and icon, and the `priority_check` package, were
  written for this project. There are no vendored libraries, web fonts or external scripts.
- `priority_check` has no runtime dependencies (Python standard library only).
- Optional, not included:
  - the LangGraph example (`package/examples/langgraph_workflow/`) needs `langgraph` (MIT licence), installed by you;
  - building the archives uses `build` and `setuptools` (MIT licence).

## Model outputs
The recorded responses shown on the site were generated by Gemini 2.5 Pro and Gemini 3.8 Flash (Google), Claude
Sonnet 5.5 (Anthropic) and GPT-5.5 (OpenAI) through their APIs. They are published as research records, under each
provider's terms for API output.

## Questionnaires
No questionnaire items are reproduced. The release was scanned against the value questionnaires used in the
research's design (PVQ-RR, PVQ-21, SBSVS) for overlapping wording. The remaining overlaps are common phrases or a journal title in a citation,
and each was reviewed before release.
