About this site

Privacy and feedback

In short

This site is a set of static files. It runs no AI, has no backend and no analytics, and sends nothing you type or open anywhere.

Privacy

What the site does. Every page is a static file. The pages load their scripts, styles and data only from this site, and every page's Content-Security-Policy forbids connections to any other address (connect-src 'none'), so the browser itself blocks a page from sending data anywhere.

What you type or open. Text you type (your workflow map, priorities, options) and files you open on the Workflow Map, Inspect and trace pages (a run's summary.json, records.jsonl, a trace) are read by your browser on your device. They are not uploaded and are gone when you close or reload the page. When you save a file (a scenario, a map), your browser writes it to your own device.

What is stored. The site sets no cookies and uses no browser storage.

Checked how. Before release we recorded every network request the browser made while going through the visitor journey (Be the Auditor) and the developer journey (Map, Test, Inspect with your own run files, Compare): every request went to this site's own address, and opening files caused no request. This describes the site's code; the hosting service that serves these files may keep its own standard access logs (for example IP address and browser type), as almost every web server does.

The Python package (priority_check) runs on your computer. It makes no network calls of its own. Your adapter calls whatever your workflow calls; the optional real-model providers call the provider you choose with the key you supply. Its results are written only to the folder you name.
